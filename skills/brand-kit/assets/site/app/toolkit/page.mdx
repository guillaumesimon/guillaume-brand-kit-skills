  <Prose>
    Change a value in `tokens.json`, then ask an agent to sync the kit, the `brand-kit-update` skill rewrites `theme.css`, the synced blocks of `BRAND.md` and the front matter of `DESIGN.md`, and rebuild this site. Never hand-edit a value on a page: the pages read every value from the tokens, so a hex typed into a page is how a brand starts to rot.

    When an agent makes something off-brand, do not just fix the output. Add the rule that would have caught it to the section of `BRAND.md` or `DESIGN.md` it governs, and log it in `CHANGELOG.md`. The `brand-kit-update` skill does this.
